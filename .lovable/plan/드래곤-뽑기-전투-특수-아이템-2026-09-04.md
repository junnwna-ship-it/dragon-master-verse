# 드래곤 뽑기 + 전투 특수 아이템

## 1. 드래곤 뽑기 (소환)

새 화면 "소환의 제단"을 로비에서 진입할 수 있게 추가합니다.

- 비용: 1회 500 골드 또는 소환 티켓 1장. 10연차는 4,500 골드(또는 티켓 10장)이며 최소 1회 레어 이상 확정.
- 티켓은 상점에서 골드로 구매하거나 스토리/퀴즈 보상으로 받습니다.
- 등급별 확률표를 화면에 항상 표시(일반 60% / 레어 30% / 영웅 8% / 전설 2%).
- 결과는 카드 뒤집기 연출로 한 장씩 공개, 10연차는 순차 공개 후 요약.
- 중복이 나오면 "드래곤 파편" 아이템으로 변환(등급별 지급량 차등). 파편을 모으면 소환 제단에서 원하는 드래곤을 직접 교환.
- 새로 얻은 드래곤은 즉시 보관함/덱에 등록되고 플레이어별 성장치로 시작.

모든 뽑기 계산·비용 차감·지급은 서버에서 처리하므로 화면에서 확률이나 결과를 조작할 수 없습니다.

## 2. 전투 특수 아이템

전투 화면에 아이템 버튼과 인벤토리 시트를 추가하고, 한 번의 사용이 한 턴을 소모합니다. 전투당 사용 가능 횟수는 3회로 제한.

준비할 아이템:
- 회복: 생명력 물약(HP 40% 회복), 마력 물약(MP 30 회복)
- 버프: 용맹의 뿔피리(1턴 공격력 +50%), 수호의 인장(2턴 방어력 +50%)
- 공격/약화: 화염 폭탄(고정 피해), 저주 부적(적 공격력 -30%, 2턴)
- 부활/보호: 불사의 깃털(패배 직전 1회 HP 30%로 부활), 성역의 방패(다음 1회 피해 무효)
- 랜덤: 혼돈의 주사위 — 위 효과 중 하나가 무작위로 발동(즉석 특수기)

동작 규칙:
- 사용 즉시 인벤토리 수량이 줄고 전투 로그에 결과 문장이 남습니다.
- 수량 0이면 버튼은 회색 비활성 + 안내 토스트.
- 부활·방패는 전투 상태에 지속 효과로 남고, 전투 종료 시 정리.
- PvP(태그 배틀)에도 동일한 아이템 패널을 붙이되 부활은 1회로 제한.

## 3. 획득 경로

- 상점에 소비 아이템/티켓 탭 추가(골드 구매, 관리자 CMS에서 가격·노출 관리).
- 스토리 노드 보상과 퀴즈 정답 보상에 아이템 지급 연결(기존 보상 시스템 재사용).
- 전투 승리 시 소량 드랍은 포함하지 않습니다(상점 + 스토리/퀴즈 보상만).

## 기술 메모

- DB: `dragon_pool`(뽑기 등급/가중치), `summon_history`, `combat_items`(CMS 관리, `is_published` 포함), 인벤토리는 기존 `user_inventory` 재사용. 모든 신설 테이블에 GRANT + RLS(관리자 전체, 유저는 공개분 SELECT / 본인 행만).
- RPC: `summon_dragon(_count int, _pay text)` — 비용 검증, 가중 추첨, 중복→파편 변환, `owned_dragons` 등록, 결과 JSONB 반환. `exchange_shards(_dragon_uuid)`, `consume_battle_item(_item_key)` (수량 차감 검증 후 효과 payload 반환).
- 프론트: `src/components/game/views/SummonView.tsx`, `src/hooks/useSummon.ts`, `src/lib/battleItems.ts`(효과 정의/적용 순수 함수 + Vitest), `BattleEngine.tsx`/`TagBattleEngine.tsx`에 아이템 패널·지속효과 상태 추가, `useInventory` 이벤트로 수량 동기화.
- 한국어/영어 로케일 문구 추가, 뽑기 화면 head() 메타데이터 포함.
