# 몰입·재미 점검 결과와 개선 방향

데이터베이스와 플레이 코드를 직접 확인한 결과, 연출보다 **콘텐츠 연결이 끊어진 것**이 몰입을 깨는 가장 큰 원인입니다.

## 지금 확인된 문제 (실제 데이터 기준)

1. **20장면 챕터인데 실제로는 5장면만 플레이됩니다.**
   `dragon_master`의 진행 경로가 Node_1 → Node_2 → **Node_12** → **Node_19** → Node_20으로 연결되어 있어, 수입한 Node_3~11, 13~18(총 15장면)은 아무 경로로도 도달할 수 없습니다.
2. **언어가 섞여 있습니다.** Node_1·2·12·19·20은 영어, Node_3~18은 한국어입니다. 게임은 한/영 언어 전환을 지원하는데 스토리 본문은 고정 텍스트라 어느 언어로 봐도 중간에 언어가 바뀝니다.
3. **퀴즈가 스토리에서 사라졌습니다.** quizzes 테이블에는 7문항이 있지만 story_nodes의 `quiz_ids`가 모든 노드에서 비어 있어, 퀴즈 분기·정답 보상이 실제 플레이에 등장하지 않습니다.
4. **스토리 진행 보상이 0입니다.** `dragon_master` 20노드 전부 `rewards`가 비어 있고 `story_reward_claims`도 0건입니다. 즉 스토리를 끝까지 봐도 성장 체감이 없습니다. (`dragon_growth` 챕터에만 보상이 붙어 있음)
5. **장면 이미지가 5장뿐입니다.** DB의 `background_image_url`은 전 노드가 비어 있고 번들 아트가 Node_1/2/12/19/20에만 존재합니다. 새 장면을 살리면 대부분이 이미지 없는 화면이 됩니다.
6. **본문이 너무 짧습니다.** 노드 평균 본문 길이가 47~57자로, 요약문 수준입니다. 비주얼 노벨의 호흡(대사·감정·묘사)이 없어 선택지의 무게가 느껴지지 않습니다.
7. **선택지가 사실상 무의미합니다.** 거의 모든 노드가 두 선택지 모두 같은 다음 노드로 수렴하고, 차이는 Courage/Worm_Affinity 등 스탯 ±5뿐입니다. 그 스탯이 결말이나 전투에 영향을 주지 않아 "내 선택이 이야기를 바꿨다"는 감각이 없습니다.
8. **PvP가 신규 유저에게 막혀 있습니다.** 프로필 22명 대비 `owned_dragons`는 1행뿐입니다. PvP는 보유 드래곤 3마리 덱이 필요하므로, 랜딩에서 PvP를 골라 들어온 유저는 "덱을 채우세요" 상태에서 멈춥니다.
9. **상점·훈련·연출 데이터가 비어 있습니다.** 공개된 store_items 0건, training_stats 0건, characters/bgm_tracks/battle_skills 0건입니다. 하단 탭 6개 중 2개가 빈 화면이고, CMS에 만든 캐릭터·BGM·스킬 탭도 아직 콘텐츠가 없습니다.

## 제안하는 개선 방향 (우선순위 순)

### 1단계 — 이야기를 다시 이어붙이기 (몰입 회복의 핵심)
- Node_1 → 2 → 3 → … → 20 순차 연결로 복원하고, 15개 잠긴 장면을 실제 플레이 경로에 넣습니다.
- 퀴즈 게이트를 이야기상 자연스러운 2~3지점(예: Node_6 이름 짓기, Node_14 붉은 구슬, Node_17 탈출)에 다시 연결하고, 실패 시 되돌아오는 노드를 지정합니다.
- 언어 통일: 스토리 본문을 한 언어 기준으로 정리하고, 다국어는 `body_text_en` 같은 병행 필드 또는 챕터 사본으로 처리합니다.

### 2단계 — 선택에 결과를 주기
- 누적 스탯(Courage / Worm_Affinity / Independence / Social)에 따라 후반 2~3개 분기와 **결말 3종**(진정한 마스터 / 홀로 선 자 / 웜을 잃은 자)이 갈리게 합니다.
- 스토리 종료 시 스탯 총합을 요약해 "당신의 웜은 이런 존재가 되었다" 카드로 보여줍니다.
- 챕터 완주 보상(골드·스탯 포인트·교감의 증표)을 중간 3지점과 END에 배치해 진행이 성장으로 이어지게 합니다.

### 3단계 — 첫 플레이 온보딩 정상화
- 스토리 초반(웜과의 첫 만남 시점)에 **첫 드래곤을 실제로 지급**해, 스토리를 끝내면 자연히 덱과 훈련·PvP로 이어지게 합니다.
- PvP 진입 시 덱이 비어 있으면 "스토리로 드래곤 얻기" 안내와 임시 연습 매치(보상 없는 튜토리얼 배틀)를 제공합니다.
- 랜딩 모드 선택에서 PvP는 조건 미달 시 잠금 배지와 이유를 함께 표시합니다.

### 4단계 — 연출 밀도 올리기
- 노드 본문을 화자(speaker) 대사 + 묘사 2~3문단으로 확장합니다.
- 장면 아트를 챕터 단위 배경 5~7종(온양 밭 / 성 / 훈련장 / 터널 / 동굴)으로 늘려 노드별로 매핑하고, CMS URL로 교체 가능하게 유지합니다.
- 챕터별 BGM 1곡과 주요 캐릭터(그리피스·롤랜드·로리·보·아나) 초상 데이터를 CMS에 채워 대사창에 표시합니다.

### 5단계 — 비어 있는 화면 채우기
- 상점 아이템 6~8종, 훈련 능력 4종을 공개 상태로 시드해 골드 사용처를 만듭니다.
- 전투 스킬 텍스트를 채워 배틀 로그가 "무엇을 했는지" 읽히게 합니다.

## 기술 메모

- 스토리 재연결·퀴즈 게이트·보상은 `story_nodes`(`options.next_node`, `quiz_ids`, `rewards`) 마이그레이션과 관리자 Story Map Editor로 처리 — 플레이어 코드 변경 최소화.
- 다중 결말은 `VisualNovelPlayer`의 누적 `stats`를 조건으로 `next_node`를 고르는 규칙 필드(예: `options[].requires`) 추가가 필요합니다.
- 첫 드래곤 지급은 기존 `recruit_dragon` RPC를 스토리 보상 경로에서 호출(멱등 처리: `story_reward_claims` 기준)합니다.
- 장면 아트는 `src/data/storyArt.ts` 매핑 확장 + DB `background_image_url` 우선 사용 구조를 그대로 활용합니다.

## 범위 확인

한 번에 전부 적용할 수도 있고, 1~2단계(끊긴 이야기 복원 + 선택의 결과)만 먼저 적용해 체감 변화를 확인한 뒤 진행할 수도 있습니다.
