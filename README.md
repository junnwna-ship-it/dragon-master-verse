# 드래곤 마스터즈 게임

[Lovable에서 제작한 웹게임](https://dragon-master-verse.lovable.app)의 소스 코드입니다. 플레이어가 직접 드래곤 마스터가 되어 자신의 드래곤을 만나고, 동료들과 함께 훈련하며 성장하는 이야기를 중심으로 구성합니다.

## 개선 계획과 작업 순서

제품의 중심은 **내가 그린 드래곤이 이름에 반응하고, 함께한 모험을 기억하는 경험**입니다. 분석 결과, 개선사항, 덱·성장·이펙트 제안과 단계별 완료 기준은 [나만의 드래곤 경험 실행 로드맵](docs/DRAGON_EXPERIENCE_ROADMAP.md)에 정리했습니다. 작업 상태와 상세 체크리스트는 해당 문서를 기준으로 관리합니다.

| 순서 | 작업 | 주요 결과 |
| --- | --- | --- |
| 0 · DM-00 | 실행·배포·저장 기준선 확인 | 재현 가능한 환경과 실제 기능 검증 |
| 1 · DM-01 | 드래곤 정체성·원본·초안 보관 | 내 그림과 설정이 사라지지 않는 제작 과정 |
| 2 · DM-02 | 드래곤과 이야기 연결 | 같은 드래곤으로 첫 만남부터 첫 성장까지 |
| 3 · DM-03 | 질문형 이야기 제작기 | 장면 문법 없이 만드는 나만의 모험 |
| 4 · DM-04 | 기억·관계·성장 앨범 | 선택을 기억하고 모습을 보존하는 성장 |
| 5 · DM-05 | 고유 능력·동료 덱·밸런스 | 사용자 드래곤도 개성 있게 활약하는 전투 |
| 6 · DM-06 | 교감·성장·전투 연출 | 효과음·접근성·모바일 성능을 포함한 연출 |

**다음 작업은 DM-00이며, 신규 단계는 모두 예정 상태입니다.** 1차 목표는 DM-00~02의 짧고 완결된 경험입니다. 장편 AI 생성·실시간 경쟁 확대는 이후로 두고, 각 단계의 완료 기준을 확인한 뒤 다음 단계로 진행합니다. 이 문서화 자체는 기능 구현이나 서비스 배포 완료를 의미하지 않습니다.

## 스토리 구성

| 모드 | 내용 |
| --- | --- |
| 나의 드래곤 만들기 | 기본 드래곤의 비늘 빛깔을 꾸미거나 손그림을 업로드/촬영합니다. 선택하면 AI가 원래 형태를 유지하며 선·색·배경을 게임 카드용으로 정돈합니다. 이름, 원소, 성격, 첫 만남과 성장 목표를 정하면 즉시 내 드래곤으로 등록됩니다. |
| 나와 내 드래곤의 첫 만남 (`my_dragon`) | 직접 만든 드래곤과 성에서 만나 첫 교감과 훈련을 합니다. |
| 내 드래곤의 성장 이야기 (`dragon_growth`) | 같은 드래곤과 연습, 실패, 재도전을 거치며 성장합니다. 이야기 보상은 보유 드래곤의 능력 포인트와 교감 아이템으로 이어집니다. |
| 1권 각색 (`dragon_master`) | 《Dragon Masters: Rise of the Earth Dragon》의 핵심 사건을 플레이어 관점으로 각색했습니다. 시작 전에 반드시 내 드래곤을 선택하며, 원작에서 웜이 맡은 동행 역할을 선택한 드래곤이 수행합니다. 선택지와 여러 엔딩은 게임 고유 각색입니다. |

원작 인물인 보·아나·로리는 플레이어의 동료 드래곤 마스터입니다. 그리피스는 멘토, 롤랜드는 왕이자 임무를 주는 인물입니다. 표기는 Rori, Ana, Bo, Griffith, King Roland 및 드래곤 Vulcan, Kepri, Shu, Worm을 기준으로 합니다. 게임 고유 수집형 드래곤과 PvP는 원작 사건의 일부로 취급하지 않습니다.

스토리 화면의 새 이미지는 어린 플레이어와 드래곤의 만남, 훈련, 동료 관계에 맞춘 독자적인 게임 삽화입니다. 원작의 삽화를 복제한 이미지가 아닙니다.

## 1권 이후 자료 범위

현재 개인 드래곤 모드는 독자적인 이야기로 진행되므로 2권 이후의 상세 줄거리가 없어도 확장할 수 있습니다. 원작 기반 후속 장을 만들 때에는 **2권의 상세 사건 순서**가 첫 번째 필요 자료입니다. 2권에서는 아나의 드래곤 케프리가 아프고, 웜의 능력으로 치료법을 찾아 나섭니다. 그다음 동료 보의 이야기까지 연속해서 구성하려면 **3권도 필요**합니다. 3권은 드래곤 스톤, 보의 행동, 보의 가족과 슈가 중심입니다. 즉 다음 장 하나를 만들면 총 2권까지, 연속된 두 장을 만들면 총 3권까지 확인하면 됩니다. 공식 소개만으로는 장면별 대화와 사건 순서를 확정할 수 없으므로, 세부 각색 전에 해당 권의 정식 자료와 사용 권한을 확인해야 합니다.

공식 줄거리: [Scholastic 시리즈 페이지](https://www.scholastic.com/site/branches/dragon-masters-bk.html), [작가 Tracey West 시리즈 페이지](https://www.traceywest.com/series/dragon-masters-series/).

## 개발과 반영

### UX/UI와 반응형 구성 (2026-09-25)

- 분위기: 기존 독자 삽화를 사용한 따뜻한 판타지 모험. 시작 화면은 이모지 잠금 카드 대신 아기 드래곤을 보여주고, 플레이어를 마법사 수습생이 아닌 드래곤 마스터로 안내합니다. 아이들이 직접 그린 카드 이미지는 유지합니다.
- 모바일: 주요 메뉴 4개(로비·이야기·보관함·훈련소)와 더보기. 상점·대결·소환은 더보기에서 접근합니다. 하단 안전 영역과 44px 이상 주요 조작 영역을 적용합니다.
- 태블릿/PC: 768px부터 로비 카드가 2열, 1280px부터 3열로 배치됩니다. 1024px부터 왼쪽 메뉴와 최대 1280px 본문 영역을 사용합니다. 보관함·훈련·소환도 넓은 화면에 맞춰 재배치됩니다.
- 드래곤 만들기: 큰 그림 미리보기, 원본 비율 유지, 이후 단계에서도 내 드래곤 표시, 입력 라벨·선택 상태·단계 이동 포커스 제공. AI 처리 중 그림 교체와 다음 단계 이동을 막아 결과가 뒤섞이지 않게 합니다.
- 스토리/팝업: 화면 높이에 맞는 대화 영역, PC 2열 선택지, 큰 동행 드래곤 이미지, 스크롤 가능한 상세창, 시작/모드 팝업의 키보드 포커스 제한과 Escape 닫기를 지원합니다. 알림은 모든 경로에서 표시됩니다.
- 함께 수정: 로비 재진입 시 개인 드래곤 목록 유지, 스캔 카드 ID 충돌 방지, 챕터/드래곤 변경 시 플레이어 재초기화, 로비 복귀 경로, 능력치의 잘못된 ‘100점 만점’ 표시.

검증: 로컬 브라우저에서 320·390·768·1024·1440px 레이아웃을 점검했습니다. 로그인 없이 임시 메모리 데이터로 실제 UI 컴포넌트를 검사했으며 검사용 경로는 제거했습니다. 제작 단계 이동·긴 이름 줄바꿈·더보기 이동·PC 카드 정렬·스토리 도입/첫 대화와 각 주요 화면의 가로 넘침을 확인했습니다. 실제 계정의 생성/구매/훈련 저장, 실기기 카메라, 유료 AI 호출은 이번 UI 검사에 포함하지 않았습니다. 서비스 DB의 기존 스토리 본문에는 영어가 남아 있으며, UI 언어 전환과는 별도입니다.

자동 테스트는 `npm test`로 실행합니다(34개). 배포 빌드는 `npm run build`입니다. 전체 TypeScript 검사에는 기존 `useCms.ts`, `router.tsx` 타입 오류 2개가 남아 있습니다.

플레이 순서는 `드래곤 만들기 → 첫 만남 → 선택한 드래곤과 1권 → 성장 이야기`입니다. 1권의 저장 기록은 드래곤별로 분리되어 같은 플레이어도 다른 드래곤과 새롭게 진행할 수 있습니다.

프로젝트에는 React, TanStack Start, Supabase를 사용합니다. 게임 코드의 새 스토리 장면과 개인 드래곤 생성 기능은 `supabase/migrations/20260925180000_player_protagonist_and_companions.sql`, `supabase/migrations/20260925181000_personal_dragon_chapters.sql`, `supabase/migrations/20260925200000_personal_dragon_creation_and_book_one.sql`에 정의되어 있습니다. GitHub에 코드가 반영되어도 서비스 데이터베이스에 이 마이그레이션이 적용되기 전에는 새 장면과 생성 기능이 표시되지 않습니다.

손그림 AI 정돈은 서버 전용 `OPENAI_API_KEY`가 필요합니다. 키는 브라우저 코드에 넣지 않으며, 배포 환경의 비밀 변수로만 설정합니다. 모델은 기본적으로 이미지 편집 정확도가 높은 `gpt-image-2.5-sunburst`를 사용하며 `OPENAI_IMAGE_MODEL`로 변경할 수 있습니다.

```sh
npm install
npm run dev
```

현재 저장소의 `package-lock.json`은 `package.json`과 버전이 일치하지 않아 `npm ci`가 실패합니다. 의존성 파일을 정리한 뒤 CI 설치와 전체 빌드를 다시 확인해야 합니다.
